## 已知边界

- Windows 上硬链接在扫描期无法识别（公开 API 无文件身份），以普通文件归档并警告；硬链接保真用例在 macOS/Linux 实跑。管道/设备/套接字同样仅 POSIX 识别（`unix:mode`）。
- 特殊文件重建依赖 `mkfifo`/`mknod` 与相应权限；无工具或无特权时降级为警告，归档与清单仍完整。套接字只记录不重建。
- 软链接属主、组、权限不回填（保护链接目标），并产生警告；链接时间仍以不跟随方式尝试恢复。
- 属主、组及创建时间受文件系统和当前用户权限限制；失败时报告属性警告，不请求提权。
- 不支持的无法分类特殊文件跳过并提示。
- 增量还原需用户依次选择全量及增量，不自动串联，不同步删除。前次恢复的只读目录可能需要用户调整权限后再叠加下一份增量。
- 保留单位是一组全量及其增量，默认 0 关闭淘汰。历史无索引或无法确认身份的备份不会被自动删除。
- 网络模式证书为自签名（SAN 含 localhost/127.0.0.1），客户端以服务器密钥库文件固定信任；面向本机与局域网使用。
