## 1. 概述

本报告的主要目的是为主要承担的测试工作制定初步要准则和规范，以及同有关方面协议对测试工作进行合理的组织管理，并证明所实现软件满足需求分析说明书与系统设计文档的全部承诺。

- **被测对象**：Backup 桌面备份软件（备份/还原/自动化/网络四模块，Java 21 实现）
- **测试依据**：`doc/需求分析说明书.md`（FR-CORE-01~08、FR-IO-01~05、FR-CRYPTO-01/02、FR-AUTO-01/02、FR-NET-01~05）、`doc/系统设计文档.md`
- **测试结论摘要**：自动化测试 **102 项全部通过**（Windows 实测，25 项为平台能力跳过；macOS 87 项全通过）；登记缺陷 10 项，**全部修复并回归**；未发现阻断性遗留缺陷。

## 3. 源码测试（代码复查）

对系统关键模块（BackupService / ArchiveService / BackupCatalog / NetworkBackupServer）进行了代码复查，检查编码规范、注释准确性、是否存在潜在缺陷：

- **规范检查**：命名一致（驼峰 + record 值对象）、方法单一职责、无魔法数字（常量化）；`mvn -B clean package` 全程无警告级失败。
- **注释检查**：所有公共类与公共方法具备 javadoc；关键算法（增量判定、组保留、路径安全、GCM 认证、FIFO 不打开流）附设计动机注释；测试类含用例清单。注释率：主代码注释行/代码行 ≈ **21.8%**（达到 20% 档）。
- **接口检查**：模块间仅依赖 record 值对象与明确接口；网络层复用本地层 API，无平行实现。
- **数据结构检查**：清单/索引 Properties 格式有版本号与边界校验；归档二进制格式所有长度字段有界。

## 7. 缺陷记录与修复

| 编号 | 现象 | 根因 | 修复 | 回归 |
| --- | --- | --- | --- | --- |
| BUG-01 | Windows 下 5 项测试失败 | JDK 公开 API 在 Windows 无 fileKey/unix:mode | 能力假设守卫 + 降级警告 + 文档记录 | 64→全绿 |
| BUG-02 | 错误口令报错为密码学堆栈原文 | CipherInputStream 把 GCM 失败吞成普通 IOException | 识别 Tag mismatch 转明确口令提示 | TC-K02 |
| BUG-03 | FIFO 还原可能永久阻塞 | 打开管道读端会等待写者 | "不打开流"不变量：mkfifo + 属性位复核 + touch 设时间 | TC-S01/02 |
| BUG-04 | 扫描器重写引入常规文件漏归档 | 分类分支未给 FILE 兜底 | 补 isRegularFile 分支 + 全量回归 | 全绿 |
| BUG-05 | 网络客户端漏带 Authorization 头 | basicToken 计算后未注入 builder | builder 统一注入 | TC-N02 |
| BUG-06 | 设备条目还原触发全量完整性误判 | 特殊文件未计入已处理集合 | skipped 语义统一（计条目、记警告） | TC-S04 |
| BUG-07 | 网络加密链跨进程断链风险 | 服务器无法校验口令一致性 | 客户端进程内口令记忆，换进程强制全量 | TC-K03 |
| BUG-08 | javadoc 含 `**/` 序列导致编译失败 | 块注释内出现 `*/` 提前终止 | 改写措辞 + 全库扫描 | 编译通过 |
| BUG-09 | 保留组序号断言方向错误 | 列表按时间倒序而断言按正序 | 修正断言（最新在前） | TC-N05 |
| BUG-10 | 服务器重复归档名可覆盖 | 提交前未查冲突 | 存在即 400 拒绝 | TC-N08 |

## 8. 测试结论

1. **功能完整性**：需求分析说明书全部 24 条功能需求均有对应测试证据（附录 A 追溯表）。
2. **正确性**：102 项自动化测试全部通过；round-trip 等价性、增量语义、组轮换、路径安全均有断言固化。
3. **健壮性**：对抗测试（穿越/篡改/伪造/截断/并发）全部通过；失败路径均"干净失败"（无半份产物、无越权写入）。
4. **平台声明**：Windows 实机 102 项（25 项 POSIX 能力跳过）；macOS 实机 87 项全通过；**不宣称未实测平台已验收**。
5. **遗留风险**：见需求书 LIM-10~13（Windows 特殊文件识别、设备特权、自签名证书信任模型、网络口令记忆模型），均有用户可见的警告与文档说明。
